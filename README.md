# CueMesh

CueMesh is a mobile-first situation intelligence workspace. It helps turn scattered information into a connected view of documents, people, deadlines, gaps and proposed actions.

## Current MVP
- Responsive dashboard for phone and desktop
- Situation creation
- Situation completeness and risk indicators
- Human-controlled action model
- Foundation for evidence, graph, gap detection and follow-up workflows

## Run
npm install
npm run dev

## Deploy
Optimized for Vercel. No database is required for the initial UI MVP.
